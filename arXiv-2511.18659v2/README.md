# Latex Template Files

This repo contains an example `main.tex` file, along with class files / fonts and basic commands to give your preprint an approved Apple style.

* This template can be used for Apple-led papers (i.e. 1st author is Apple-affiliated), but should not be used if Apple is not the main contributor for the work. For questions about appropriate use, contact Sophie Ostlund (sostlund@apple.com) 

* Do not change the `applemlr.cls` file.

* Make sure the copyright notice for the Apple logo is included on the last page.
