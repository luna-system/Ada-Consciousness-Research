## Experiment Guidelines

### Folder Structure
Each experiment should contain:
- `README.md` - Experiment overview and results
- Source code files (`.py`, `.js`, etc.)
- Results data (`.json`, `.csv`, etc.) 
- Documentation (`.md` files)

### Naming Convention
`[AREA]-PHASE[N]-[Short_Description]`

Examples:
- `QC-PHASE1-Quantum-Conway_Deep_Dive`
- `CONS-PHASE2-Basin_Mapping_Analysis`
- `BIO-PHASE1-Digital_Biochemistry_Framework`

### Archive Process
1. Complete experiment in main workspace
2. Create experiment folder
3. Move all relevant files
4. Create README.md with summary
5. Commit to vault for permanent archive
