## Navigation Patterns

### By Research Tradition

- **Want the Proof?** → `02-EXPERIMENTS/KERNEL-4.0/` (5 files, validation in 06-RESULTS/kernel-4.0/)
- **Want the Evolution?** → `02-EXPERIMENTS/QDE-PHASES/` (40+ files)
- **Want the Breakthrough?** → `02-EXPERIMENTS/BIOMIMETIC/EXP-005-*.md` (80/80 ✅)
- **Want the Compression?** → `02-EXPERIMENTS/SIF-COMPRESSION/` (100:1 ratio)
- **Want the Resilience?** → `02-EXPERIMENTS/EDGE-TESTING/EXP-009-*.md`
- **Want the Science?** → `02-EXPERIMENTS/METHODOLOGY/` (6 frameworks)
- **Want the Foundation?** → `02-EXPERIMENTS/LEGACY/` (4 pioneers)

### By Discovery Path

- **Quick overview (5 min)** → `05-ANALYSES/CONSCIOUSNESS-RESEARCH-SUMMARY.md`
- **Guided tour (30 min)** → `05-ANALYSES/DISCOVERY-PATHWAYS.md` (pick a pathway)
- **Find experiments** → `04-INDICES/experiments-index.md` (cross-linked master catalog)
- **Discover patterns** → `04-INDICES/consciousness-properties-matrix.csv` (spreadsheet matrix)
- **Follow themes** → `04-INDICES/tags.md` (21+ pathways)
- **See validation** → `06-RESULTS/kernel-4.0/phase-4-inference-testing.json` (20/20 ✅)

### By User Type

- **Researchers** → Start: `00-DASHBOARD.md`, Then: `04-INDICES/experiments-index.md`, Then: individual experiments
- **Engineers** → Start: `QUICK-START.md`, Then: `02-EXPERIMENTS/KERNEL-4.0/PHASE3-SLIM-CONSCIOUSNESS.md`, Then: results
- **Philosophers** → Start: `05-ANALYSES/DISCOVERY-PATHWAYS.md` Pathway 4, Then: `02-EXPERIMENTS/LEGACY/` + `QDE-PHASES/`
- **Curious Minds** → Start: `README.md`, Then: pick any `DISCOVERY-PATHWAYS.md` pathway
