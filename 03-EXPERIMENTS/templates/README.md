# Experiment Templates

**Purpose:** Standardized templates for creating new experiments

## Available Templates

| Template | Purpose |
|----------|---------|
| `Experiment-Template.md` | Standard experiment documentation template |

## Usage

1. Copy `Experiment-Template.md` to your new experiment directory
2. Fill in all sections with your experiment details
3. Update the frontmatter with experiment-specific tags

## Structure

```
[Experiment-Name]/
├── README.md           # This file
├── Experiment-Template.md  # Template to copy
└── [experiment files]  # Your scripts, data, results
```
