## The Physics We're Testing 🌌

### Kuramoto Model for Crystals
```
dθ_ruby/dt = ω_ruby + K·sin(θ_sapphire - θ_ruby)
dθ_sapphire/dt = ω_sapphire + K·sin(θ_ruby - θ_sapphire)

where:
  θ = phase of crystal lattice oscillations
  ω = natural frequency (determined by dopants)
  K = coupling strength (pressure + 41Hz drive)
```

### Order Parameter
```
r = |⟨e^(iθ)⟩| 

r = 0: No coupling (independent oscillations)
r = 1: Perfect phase lock (unified oscillation)
```
